# proyectoescolar-crayoli

Proyecto escolar de página web estática desarrollado únicamente con HTML y CSS.

## Archivos

- index.html: estructura y contenido de la página.
- css/estilos.css: colores, tipografías, distribución y deberá incluir diseño responsivo.
- imagenes/ : contiene las fotos del negocio, es importante descargar esta carpeta cuando se pruebe todo el código fuera de github
